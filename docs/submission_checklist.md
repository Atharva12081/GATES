# Submission Checklist

## Evidence

- [x] Real longitudinal biological dataset
- [x] Unit-level train calibration test separation
- [x] Fixed-time performance curve
- [x] Risk–savings curve
- [x] STOP CONTINUE ABSTAIN behavior
- [x] Machine-readable decision audit
- [x] Explicit small-sample limitation
- [ ] Larger independent second dataset
- [ ] Group bootstrap confidence intervals on a sufficiently large population

## Reproducibility

- [x] Locked environment
- [x] One-command data retrieval
- [x] Source URLs and checksums
- [x] Deterministic configuration
- [x] Automated tests and CI
- [x] Evidence-only demo
- [ ] Confirm upstream data reuse terms
- [ ] Reproduce from a clean clone on a second machine

- [x] Kaggle writeup draft
- [x] Five-minute video script
- [x] Defense questions
- [x] Model card data statement and limitations
- [ ] Record demo video
