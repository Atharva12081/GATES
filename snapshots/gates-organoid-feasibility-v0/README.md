# GATES OrganoID Feasibility v0

This directory records the immutable feasibility snapshot. The annotated Git tag
`gates-organoid-feasibility-v0` identifies the exact source, lockfile, evidence tables, figure,
configuration, and serialized models. Phase 2 outputs must use separate paths and must not replace
the tagged artifacts.

Raw upstream tables are intentionally not committed because the OrganoID repository has no detected
license. Their exact source URLs and SHA-256 checksums are recorded in the data manifest and
`FREEZE.json`.
